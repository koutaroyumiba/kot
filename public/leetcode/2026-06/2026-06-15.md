First thoughts, I need to get the characters and the count from the string `t` and then make a sliding window over string `s` keeping track of the characters that are within the sliding window.

I am going to re-use the count map over the string `t` and just decrement from it to keep track of the characters in the window (so that we just need to check that all the character count is 0 for the answer to be valid)

In the loop:
- add the current right element into the window
- if this element brings the char_count to negative, then we try to shift the leftmost pointer, stopping when the left pointer is about to delete a character we need.
- we continue this while keeping track of the minimum length of a valid answer.

One mistake that I made was in my `valid_answer` function where I was checking if all the counts was 0 but it should check if the count is less than or equal to 0 (even if the counts are negative, it should be still a valid answer).

```python
class Solution:
    def minWindow(self, s: str, t: str) -> str:

        def valid_answer(char_map):
            for value in char_map.values():
                if value > 0:
                    return False
            return True

        min_string = None
        t_char = {}
        for c in t:
            t_char[c] = t_char.get(c, 0) + 1

        left = 0
        right = 0
        while right < len(s):
            current_char = s[right]
            if current_char in t_char:
                t_char[current_char] -= 1
                while left < right:
                    tmp_char = s[left]
                    if tmp_char in t_char:
                        if t_char[tmp_char] < 0:
                            t_char[tmp_char] += 1
                        else:
                            break
                    left += 1
                if valid_answer(t_char):
                    if min_string is None:
                        min_string = s[left:right + 1]
                    if right - left + 1 < len(min_string):
                        min_string = s[left:right + 1]
            right += 1

        if min_string: return min_string
        return ""
```

> Time Complexity: `O(m + n)`
>
> Space Complexity: `O(n)`
>
> Time Taken: `26m 57s`
